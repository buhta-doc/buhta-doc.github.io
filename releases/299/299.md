## Добавление новой возможности

#### 26831
Изменен формат выгрузки ответа на требования ФНС по НДС - версия 5.04
Доработана выгрузка XML в форме __Стандартная. Декларация по НДС 2015. Экспорт в XML__
>вкладка __Ответ на требования о пояснениях» / книги покупок и продаж, журналы СФ)__
Изменения в скрипте формы (`[Форма].[Скрипт]`), правки в районе строк 4500–5190:

- **Версия формата 5.02 > 5.04.** Для периодов начиная с 2017 г. `ВерсФорм` теперь `5.04`.
- **КПП контрагентов.** Добавлены поля `[КПП]` / `[Посред КПП]` (а также
  `[КПП Посредника]`, `[Пост_ОргКПП]` / `[Посред_ОргКПП]`) в SQL-списки полей и в
  выходной XML — атрибут `КПП` для продавца/покупателя/посредника
  (`SetOneNodeAttr(Node5, 'КПП', …)`). Для юрлиц рядом с `ИННЮЛ` теперь пишется `КПП`.
- **Стоимость по валюте.** Вместо безусловного `СтоимПродСФВ` теперь по коду валюты:
  для пустой / `643` (рубли) пишется `СтоимПродСФ`, иначе — `СтоимПродСФВ`.
- **Документ подтверждения для книги покупок.** Для разделов 8/81 узел переименован
  в `ДокПдтвУпл` / `НомДокПдтвУпл` / `ДатаДокПдтвУпл` (вместо `ДокПдтвОпл` /
  `НомДокПдтвОпл`); для остальных разделов оставлен прежний `ДокПдтвОпл`.

#### 26834
В форму __Блокировка. Запись уже редактируется другим пользователем__
добавлена обработка клавиш __Ctrl+Alt+F2__ (метод ResoreFormPosition)
для возврата формы в позицию разработчика. 

>Будет актуально для 2-х мониторных конфигураций.
>>Описание проблемы:
Пользователь работает удаленно в 2-х мониторной конфигурации, затем не закрывает сессию, берет ноутбук, подключается и не видит формы открытые на 2-м мониторе.

#### 26836
1. В форме __Стандартная.Трудовая книжка Карточка__ (таблица [Кадры Трудовая книжка].[Документ название]) увеличина длина поля [Документ-основание] до 70 знаков.
2. В форме __Стандартная.Кадры Приказ__ (таблица [Кадры Приказ].[Цель командировки]) увеличина длина поля [Цель командировки] до 100 знаков. В карточке поле сделано многострочным.
