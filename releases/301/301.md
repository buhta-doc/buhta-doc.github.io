## Добавление новой возможности

#### 26864
Добавлена возможность экспорта многоуровневых заголовков сводных отчетов в файл Excel формата __xlsx__.

#### 26866
Для предотвращения появления ошибки, при составлении книг покупок\продаж, связанной с превышением максимальной длины поля __Авансовые счета-фактуры__ сделано следующее:

- В таблицах [Книга покупок результат], [Книга продаж результат], [#Книга покупок доплист], [#Книга продаж доплист] заменен тип поля [Авансовые счета-фактуры] с varchar(500) на varchar(max).
- Внесены изменения в модули bmBuyBookLookForm, bmSaleBookLookForm- колонка [Авансовые счета-фактуры] сделана видимой.
- Увеличена длина колоки  MainMemDataSet.MemAvansSchF до 8000 символов.

>Требуется импорт из файла BuhtaConfig.mdb (от 17.08.2026 или позднее)

#### 26870
В контекстное меню поля с типом __ссылка__ или __субконто__ добавлен пункт __"Сервис движение (склад)"__.
>Пункт отображается при наличии складских лицензий. 
>>Если поле ссылается на таблицы (ТМЦ, Партия ТМЦ, Паллета)
по нажатию вызывается форма __скл_Сервис.Движение__ с установкой параметров из вызываемой формы.
