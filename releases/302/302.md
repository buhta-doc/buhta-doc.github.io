## Добавление новой возможности

#### Современный встроенный браузер в формах
В конструкторе форм на странице палитры __БУХта__ появился компонент __TbmWebBrowser2__ — встроенный браузер на движке Microsoft Edge WebView2 (Chromium). В отличие от прежнего компонента __TWebBrowser__ (на основе Internet Explorer), он правильно показывает современные страницы: HTML5, CSS Grid, JavaScript ES6, `fetch`, `async/await`.

Возможности компонента:

- открыть адрес (свойство __DefaultURL__, метод __Navigate__) или показать HTML из строки (__LoadHtml__);
- обмен данными между страницей и скриптом формы в обе стороны: методы __ExecuteScript__, __PostWebMessageAsJson__ и событие __OnWebMessageReceived__;
- доступ страницы к данным БУХты без сети: при __AllowSqlBridge = True__ на странице доступен объект `window.bm` (`LoadFromSql`, `GetValue`, `Exec`, `LoadFromView`, `Ping`). Запросы выполняются под подключением текущего пользователя и отвечают только страницам из списка __TrustedOrigins__. Изменения данных через `window.bm` не попадают в журнал изменений формы (Кто/Когда/Что изменил);
- сохранение страницы в PDF (__PrintToPdf__) и инструменты разработчика (__ShowDevTools__, F12).

__Примеры скриптов формы__ (компонент на форме называется __bmWebBrowser21__)

Показать HTML или открыть страницу. Вызывать можно сразу, не дожидаясь, пока браузер запустится: команды выполнятся, как только он будет готов.

```pascal
procedure Button1Click(Sender: TObject);
begin
  bmWebBrowser21.LoadHtml('<html><body><h1>Остатки</h1><div id="sum"></div></body></html>');
  // или страница из файла:
  // bmWebBrowser21.Navigate('file:///C:/Buhta/pages/ostatki.html');
end;
```

Передать данные на страницу — выполнить JavaScript или отправить объект JSON:

```pascal
procedure Button2Click(Sender: TObject);
begin
  bmWebBrowser21.ExecuteScript('document.getElementById("sum").innerText = "12 345,00";');
  bmWebBrowser21.PostWebMessageAsJson('{"cmd":"setRows","n":42}');
end;
```

На странице объект принимается так: `window.chrome.webview.addEventListener('message', e => { if (e.data.cmd === 'setRows') ... });`

Получить данные со страницы. На странице: `window.chrome.webview.postMessage('SAVE:' + document.getElementById('sum').innerText);`, в скрипте формы — обработчик события __OnWebMessageReceived__:

```pascal
procedure bmWebBrowser21WebMessageReceived(Sender: TObject; const Msg: string);
begin
  if Copy(Msg, 1, 5) = 'SAVE:' then
    ShowMessage('Пришло со страницы: ' + Copy(Msg, 6, Length(Msg)));
end;
```

Дать странице доступ к данным через `window.bm`. Страницу открывать через __Navigate__ (для `LoadHtml` мост по умолчанию не работает):

```pascal
procedure FormShow(Sender: TObject);
begin
  bmWebBrowser21.AllowSqlBridge := True;
  bmWebBrowser21.Navigate('file:///C:/Buhta/pages/ostatki.html');
end;
```

На странице: `const n = await bm.GetValue('SELECT COUNT(*) FROM ТМЦ');` (внутри `async`-функции; ошибка SQL приходит как исключение — `try/catch`).

Проверить, запустился ли браузер, и сохранить страницу в PDF:

```pascal
procedure Button3Click(Sender: TObject);
begin
  if bmWebBrowser21.Failed then
    ShowMessage(bmWebBrowser21.LastError)
  else
    bmWebBrowser21.PrintToPdf('C:\Buhta\ostatki.pdf');
end;
```

Старый компонент __TWebBrowser__ продолжает работать в существующих формах, переделывать их не нужно.

>Требуется Windows 10/11 или Windows Server 2016 и новее, Microsoft Edge WebView2 Runtime (в Windows 10/11 и Windows Server 2022 обычно уже установлен) и файл __WebView2Loader.dll__ рядом с __BuhtaClient.exe__ (входит в поставку).
>>Если встроенный браузер запустить нельзя (Windows XP/7/8, не установлен WebView2 Runtime, нет файла WebView2Loader.dll), при открытии формы один раз за сеанс выводится сообщение с причиной, например «Встроенный браузер недоступен в Windows XP. Он работает только в Windows 10 и новее», и тот же текст показывается на месте компонента. Остальная программа работает как обычно.

## Исправление ошибок

#### Мобильный режим на большом экране
При запуске программы в мобильном режиме (ключ __-MOBILE:N__) на компьютере с большим экраном показывались рабочий стол, панель задач и главное меню.

__Что сделано__

В мобильном режиме на большом экране рабочий стол, панель задач и главное меню скрываются — видны только окна мобильных форм.
